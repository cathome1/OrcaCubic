# OrcaCubic

Кроссплатформенный нативный плагин для **OrcaSlicer 2.5+**, добавляющий удалённую печать, живой мониторинг, управление печатью, просмотр USB-камеры и клиентские таймлапсы для **всех FDM-принтеров Anycubic с Anycubic Cloud** (*Kobra 2 / 2 Pro / 2 Plus / 2 Max, Kobra 3 / 3 V2 / 3 Max, Kobra S1 / S1 Max, Kobra X* и др. на стоковой прошивке) — без флешек, без Rinkhals и без запуска Anycubic Slicer Next.

> **OrcaCloud Plugin Hub (установка в один клик):** https://cloud.orcaslicer.com/app/plugins/plugin-hub/33add895-117e-47ea-a4b1-b0d2650b5e0c  
> **Платформы:** macOS · Windows · Linux  
> **Языки интерфейса:** English · Русский (автоопределение + переключатель `EN / RU`)  
> **Зависимости:** Python 3 (только стандартная библиотека, 0 сторонних пакетов)  
> **Лицензия:** [MIT](LICENSE)

---

## Возможности

- **Нативная печать кнопками OrcaSlicer 2.5+:**
  - **«Распечатать стол» (Print plate)** — загрузка и мгновенный старт печати через Anycubic Cloud (с автоматической адаптацией метаданных `.gcode` для Kobra 2 Pro без изменения траекторий).
  - **«Отправить» (Send)** — загрузка `.gcode` в облачную библиотеку Anycubic Cloud без запуска печати.
- **Панель мониторинга и управления (вкладка `OrcaCubic`):**
  - прогресс `%`, текущий/общий слой, оставшееся время и расчётное время окончания (ETA), температуры сопла и стола (автообновление каждые 10 секунд);
  - кнопки **Пауза / Продолжить / Стоп** и переключение **скорости печати** (`Тихий` / `Стандартный` / `Спорт`) с изоляцией по каждому принтеру;
  - **поиск и фильтр по статусу** (удобно для ферм из нескольких принтеров).
- **Живое видео с USB-камеры (AWS KVS WebRTC):**
  - просмотр камеры прямо внутри OrcaSlicer, включается по кнопке (не тратит трафик в фоне);
  - **выравнивание горизонта** (`-45° .. +45°`), поворот `+90°`, отражение по горизонтали/вертикали, авто-масштабирование без чёрных углов и полноэкранный режим; настройки трансформации сохраняются отдельно для каждого принтера;
  - автоматическое переподключение при обрыве потока.
- **Клиентские таймлапсы (свёрнутая опциональная панель под камерой):**
  - режимы съёмки: **по интервалу**, **по смене слоя**, **парковка головы**;
  - опциональный **автозапуск записи** при старте печати и **автосохранение** при завершении печати;
  - выбор папки сохранения через нативный диалог ОС (macOS / Windows / Linux), сохранение в `.mp4` / `.webm`.
- **Облачная библиотека Anycubic Cloud:**
  - отображение занятого/общего места в облаке;
  - запуск печати (в том числе для файлов, не проиндексированных облаком) и удаление файлов в один клик.
- **Удобная и безопасная авторизация:**
  - **вход в один клик на всех ОС:** на macOS открывается нативное окно `WKWebView`, на Windows и Linux — чистое окно входа через установленный Microsoft Edge / Google Chrome / Chromium с автоматическим захватом `XX-Token` и закрытием окна;
  - запасной ручной ввод `XX-Token` из браузера на случай отсутствия Chromium-браузера;
  - токен хранится локально в папке данных плагина (`data/config.json`, права `0600`) и никогда не попадает в логи или git.

## Установка и обновление

Склонируйте репозиторий и запустите универсальный установщик:

```bash
git clone https://github.com/cathome1/OrcaCubic.git
cd OrcaCubic
python3 scripts/install.py
```

На Windows можно использовать `py scripts/install.py`.

Установщик автоматически определит каталог `orca_plugins` для вашей ОС:
- **macOS:** `~/Library/Application Support/OrcaSlicer/orca_plugins/orcacubic/` *(также скомпилирует `bin/anycubic-login-helper`, если установлен `swiftc`)*
- **Windows:** `%APPDATA%\OrcaSlicer\orca_plugins\orcacubic\`
- **Linux:** `~/.config/OrcaSlicer/orca_plugins/orcacubic/`

Для **обновления** просто выполните `git pull && python3 scripts/install.py` — ваш `data/config.json` с токеном и настройками не перезаписывается.

## Настройка в OrcaSlicer 2.5+

1. Перезапустите **OrcaSlicer 2.5+** и подтвердите запрос разрешений плагина **OrcaCubic** (сеть для `cloud-universe.anycubic.com` / облачного хранилища / AWS KVS, чтение нарезанного G-code, запуск helper-процесса).
2. Включите поддержку Printer Agents:
   - **Preferences → Developer → Experimental Features → Use printer agents instead of print hosts** (`use_printer_agents`).
3. Привяжите агент к профилю принтера (например, **Anycubic Kobra 2 Pro**):
   - **Printer settings → Basic information → Advanced → Printer Agent** → выберите **`Anycubic Cloud`**.
4. Откройте вкладку **OrcaCubic** в OrcaSlicer:
   - Нажмите **«Войти в Anycubic Cloud»** (или вставьте `XX-Token` вручную в раскрывающемся блоке).
5. **Разовая привязка во вкладке «Устройство» (Device):**
   - Выберите обнаруженный принтер `ACCloud - <Имя принтера>`.
   - Если OrcaSlicer запросит 8-значный **Access Code**, введите любые 8 цифр (например, `12345678`) — реальная авторизация выполняется через ваш `XX-Token`.
6. Нарежьте модель и нажмите **«Распечатать стол» (Print plate)** или **«Отправить» (Send)**.

## Обновление токена

Если срок действия сессии истёк, плагин покажет уведомление:
- Откройте вкладку **OrcaCubic** → нажмите **«Войти в Anycubic Cloud»** (или **«Сменить аккаунт»**).
- **Ручной способ (Windows / Linux / macOS):** войдите на `https://cloud-universe.anycubic.com/` в браузере, выполните в DevTools Console `window.localStorage["XX-Token"]` и вставьте значение в блок *«Войти через браузер / вставить XX-Token вручную»*.

## Структура проекта

```text
OrcaCubic/
├── plugin/orcacubic_plugin.py       # Точка входа плагина OrcaSlicer 2.5+ (PrinterAgent + UI)
├── orcacubic/
│   ├── auth.py                      # Подпись запросов Anycubic Cloud (MD5, заголовки, ошибки)
│   ├── client.py                    # REST-клиент Anycubic Cloud (статус, загрузка, печать, облако)
│   ├── camera.py                    # AWS SigV4 и сигналинг AWS KVS WebRTC для USB-камеры
│   ├── gcode_adapter.py             # Адаптация метаданных OrcaSlicer .gcode под Anycubic Cloud
│   ├── config.py                    # Локальное хранилище настроек (0600) и маскирование токена
│   └── login_helper.py              # Запуск нативного окна входа / диалога выбора папки
├── macos_login/                     # Swift-утилита (WKWebView + NSOpenPanel) для macOS
├── scripts/                         # Кроссплатформенный установщик (install.py, install_macos.sh)
└── tests/                           # Автотесты (unittest)
```
