# OrcaCubic

Кроссплатформенный нативный плагин для **OrcaSlicer 2.5+**, добавляющий удалённую печать, живую MQTT-телеметрию, управление печатью, просмотр USB-камеры и клиентские таймлапсы для **всех FDM-принтеров Anycubic с Anycubic Cloud** (*Kobra 2 / 2 Pro / 2 Plus / 2 Max, Kobra 3 / 3 V2 / 3 Max, Kobra S1 / S1 Max, Kobra X* и др. на стоковой прошивке) — без флешек, без Rinkhals и без установки Anycubic Slicer Next.

> **OrcaCloud Plugin Hub (установка в 1 клик прямо в OrcaSlicer, рейтинг «Низкий риск»):** https://cloud.orcaslicer.com/app/plugins/plugin-hub/33add895-117e-47ea-a4b1-b0d2650b5e0c  
> **Платформы:** macOS · Windows · Linux  
> **Языки интерфейса:** English · Русский (автоопределение + кнопка `EN / RU` в шапке)  
> **Зависимости:** Python 3 (чистый stdlib, 0 сторонних пакетов)  
> **Лицензия:** [MIT](LICENSE)

---

## Возможности

- **Поддержка всех FDM-принтеров Anycubic Cloud:** автоматическое обнаружение всех принтеров аккаунта (*Kobra 2 / 3 / S1 / X*), умный выбор онлайн-принтера, поиск и фильтр по статусу для ферм, поддержка `ams_box_mapping` (ACE Pro).
- **Нативная печать штатными кнопками OrcaSlicer 2.5+ (`PrinterAgent`):**
  - **«Распечатать стол» (Print plate)** — загрузка `.gcode` / `.3mf` (с автоматической адаптацией метаданных) и мгновенный старт печати через Anycubic Cloud.
  - **«Отправить» (Send)** — загрузка `.gcode` в облачную библиотеку Anycubic Cloud без запуска печати.
- **Живой мониторинг (MQTT + REST) и управление (вкладка `OrcaCubic`):**
  - встроенный pure-Python **MQTT-клиент** (`mqtt-universe.anycubic.com:8883`, 0 зависимостей) для мгновенных обновлений статуса, слоёв, прогресса и живых целевых температур;
  - отображение этапа **загрузки файла на принтер** в %, прогресса печати, слоёв, оставшегося времени и ETA, температур сопла и стола;
  - кнопки **Пауза / Продолжить / Стоп** и переключение **скорости печати** (`Тихий` / `Стандартный` / `Спорт`) с изоляцией по каждому принтеру;
  - полная **EN / RU локализация** (автоопределение языка системы + переключатель `EN / RU`).
- **Живое видео с USB-камеры (AWS KVS WebRTC):**
  - просмотр камеры прямо внутри OrcaSlicer, включается по кнопке (не тратит трафик в фоне);
  - **выравнивание горизонта** (`-45° .. +45°`), поворот `+90°`, отражение по горизонтали/вертикали, авто-масштабирование без чёрных углов и полноэкранный режим; настройки сохраняются отдельно для каждого принтера;
  - автоматическое переподключение при обрыве потока *(протокол Agora на новых прошивках Kobra 3 / S1 определяется корректно и запланирован в следующих версиях)*.
- **Клиентские таймлапсы (свёрнутая опциональная панель под камерой):**
  - режимы съёмки: **по интервалу**, **по смене слоя**, **парковка головы**;
  - опциональный **автозапуск записи** при старте печати (с уважением к ручной остановке) и **автосохранение** при завершении печати;
  - выбор папки сохранения через нативный диалог ОС (macOS / Windows / Linux), сохранение в `.mp4` (macOS) или `.webm` / `.mp4` (Windows / Linux) с проверкой заголовков видеоконтейнера.
- **Облачная библиотека Anycubic Cloud:**
  - отображение занятого/общего места в облаке;
  - запуск печати (в том числе для файлов, не проиндексированных облаком) и удаление файлов в один клик.
- **Удобная и безопасная авторизация (без Anycubic Slicer Next):**
  - **вход в один клик на всех ОС:** на macOS — нативное окно `WKWebView` (при локальной установке) или чистое окно Chrome/Edge; на Windows и Linux — чистое окно Microsoft Edge / Google Chrome / Chromium с автоматическим захватом `XX-Token` и закрытием окна;
  - запасной ручной ввод `XX-Token` из браузера;
  - токен хранится только локально в папке данных плагина (`data/config.json`, права `0600`) и никогда не попадает в логи или git.

## Установка

### Способ 1 — через OrcaCloud Plugin Hub (рекомендуется)
1. Откройте в **OrcaSlicer 2.5+** меню **Плагины (Plugins)** → найдите **OrcaCubic (Anycubic Cloud)** (или перейдите по ссылке: https://cloud.orcaslicer.com/app/plugins/plugin-hub/33add895-117e-47ea-a4b1-b0d2650b5e0c).
2. Нажмите **Установить / Подписаться** и включите плагин.

### Способ 2 — локальная установка из исходников (macOS / Windows / Linux)
```bash
git clone https://github.com/cathome1/OrcaCubic.git
cd OrcaCubic
python3 scripts/install.py
```
*(На Windows можно использовать `py scripts/install.py`. На macOS скрипт дополнительно соберёт нативное окно входа `WKWebView`, если установлен `swiftc`.)*

Для обновления локальной установки выполните `git pull && python3 scripts/install.py` — сохранённый `data/config.json` не перезаписывается.

## Настройка в OrcaSlicer 2.5+

1. Перезапустите **OrcaSlicer 2.5+** и подтвердите запрос разрешений плагина **OrcaCubic** (сеть `cloud-universe.anycubic.com`, `mqtt-universe.anycubic.com`, AWS KVS, чтение нарезанного G-code).
2. Включите поддержку Printer Agents:
   - **Preferences → Developer → Experimental Features → Use printer agents instead of print hosts** (`use_printer_agents`).
3. Привяжите агент к профилю вашего принтера Anycubic:
   - **Printer settings → Basic information → Advanced → Printer Agent** → выберите **`Anycubic Cloud`**.
4. Откройте вкладку **OrcaCubic** в OrcaSlicer:
   - Нажмите **«Войти в Anycubic Cloud»** (или вставьте `XX-Token` вручную в раскрывающемся блоке).
5. **Разовая привязка во вкладке «Устройство» (Device):**
   - Выберите обнаруженный принтер `ACCloud - <Имя принтера>`.
   - Если OrcaSlicer запросит 8-значный **Access Code**, введите любые 8 цифр (например, `12345678`) — реальная авторизация выполняется через ваш `XX-Token`.
6. Нарежьте модель и нажмите **«Распечатать стол» (Print plate)** или **«Отправить» (Send)**.

## Структура проекта

```text
OrcaCubic/
├── plugin/orcacubic_plugin.py       # Точка входа плагина OrcaSlicer 2.5+ (PrinterAgent + UI + EN/RU i18n)
├── orcacubic/
│   ├── auth.py                      # Подпись запросов Anycubic Cloud (MD5, заголовки, ошибки)
│   ├── client.py                    # REST-клиент Anycubic Cloud (статус, загрузка, печать, облако)
│   ├── mqtt_client.py               # Pure-stdlib MQTT 3.1.1 over TLS клиент (живая телеметрия)
│   ├── camera.py                    # AWS SigV4 и сигналинг AWS KVS WebRTC для USB-камеры
│   ├── gcode_adapter.py             # Адаптация метаданных OrcaSlicer .gcode под Anycubic Cloud
│   ├── config.py                    # Локальное хранилище настроек (0600) и маскирование токена
│   └── login_helper.py              # Окно входа (macOS WKWebView / Edge·Chrome CDP) и выбор папки
├── macos_login/                     # Swift-утилита (WKWebView + NSOpenPanel) для macOS
├── scripts/                         # Установщик (install.py) и сборщик PEP 427 wheel (build_wheel.py)
└── tests/                           # Автотесты (unittest + проверка синтаксиса встроенного JS)
```
